# Convertê

Landing page institucional da Convertê, estúdio solo de páginas que vendem para pequenos negócios locais (clínicas, salões, restaurantes, infoprodutores e prestadores de serviço).

## Sobre

Site de portfólio da própria Convertê: apresenta a oferta, o processo de trabalho, modelos de estrutura por nicho e a faixa de investimento, com um caminho direto de contato via WhatsApp.

## Tecnologias

- HTML5 semântico
- CSS puro (variáveis CSS, mobile-first, sem framework)
- JavaScript vanilla (sem dependências)

Sem build step, sem npm, sem bundler — é só abrir o `index.html` ou subir os arquivos em qualquer host estático.

## Estrutura

```
convertê-portfolio/
├── index.html   # marcação
├── style.css    # todo o visual
├── script.js    # botão de voltar ao topo
└── README.md
```

## Rodando localmente

Não precisa de instalação. Duas formas:

1. Duplo clique em `index.html`
2. Ou, pra simular um servidor real (recomendado, evita comportamentos estranhos com caminhos relativos):

```bash
python -m http.server 8000
```

Depois acesse `http://localhost:8000`.

## Deploy

Hospedado gratuitamente no [Netlify](https://netlify.com). Basta arrastar a pasta pro [Netlify Drop](https://app.netlify.com/drop) ou conectar este repositório no painel do Netlify pra deploy automático a cada push.
